# 🧮 Calculadora Web

Calculadora web responsiva desenvolvida com HTML, CSS e JavaScript puro, com foco em lógica de programação, manipulação do DOM e experiência do usuário.

## 🚀 Funcionalidades

- Operações matemáticas básicas
- Cálculo de porcentagem
- Suporte ao teclado físico
- Feedback visual ao pressionar teclas
- Exibição da expressão matemática
- Histórico de operações
- Persistência do histórico com localStorage
- Tema claro e escuro
- Layout responsivo

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura semântica
- **CSS3:** estilização, Grid, Flexbox e Media Queries
- **JavaScript:** lógica, eventos e manipulação do DOM
- **localStorage:** armazenamento de dados no navegador

## 📁 Estrutura do projeto

```text
calculadora-js/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
